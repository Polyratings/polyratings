# Frontend visual refresh

**Status:** complete on `feat/frontend-theme-tokens` (PR #248), landed as a single squashed commit after rebase onto `beta`.

**End state:** same product and information architecture, Cal Poly green/gold UI, shadcn/ui on Tailwind v4. Not a Next.js rewrite; not new copy.

## What shipped

| Slice | Contents |
| --- | --- |
| Tokens | Tailwind v4 `@theme` in `packages/frontend/src/index.css`, `cn()`, shared field classes |
| shadcn | `components.json`, CSS vars mapped onto Cal Poly tokens, Nunito on `body` |
| Forms | Wrapped form APIs with shadcn primitives (`button`, `input`, `textarea`, `checkbox`, `select`) |
| Overlays | Dialog / Sonner / nav Sheet (replaced react-modal, react-toastify, hamburgers) |
| Widgets | Combobox, slider, star rating, spinner (replaced Downshift, rc-slider, react-star-ratings, react-spinners) |
| Pages | Home, search, professor, static pages, login, new/evaluate professor |
| Admin | shadcn Table; removed leftover UI packages |
| Chrome | Desktop + mobile polish, course filter bar, theme toggle / dark mode |

Keep React, Vite, Tailwind v4, React Router, tRPC. Playwright stays 1:1 with `packages/e2e/docs`. Frontend conventions: `index.ts` re-exports, no `../` imports, one public component per file (`components/ui/*` generated by shadcn is the exception). Theming conventions live in `AGENTS.md`.
